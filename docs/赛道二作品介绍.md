# 《难得读书》· 赛道二「让一本书鲜活起来」作品介绍

> 提交口径版本｜可直接用于复赛材料、演示视频与 PPT 文案

---

## 一句话定位

**《难得读书》让你以第一人称走进经典名著主角的真实命运——在原著的关键抉择点上亲手做选择，在无法改变的结局里，照见你自己。** 它不是把书读短，而是为"读不进经典"的读者，造一个能亲身经历的入口。

---

## 一、所选书籍及版本

- **主叙述书目**：《三国演义》（罗贯中，**公有领域**经典白话小说，明代成书，现代排印本文本已进入公版）。
- **主叙述人物线**：**诸葛亮**——从「隆中对·三分天下」到「五丈原·秋风病逝」的完整命运弧线。
- **可复用范围**：同一套叙事引擎已覆盖《红楼梦》（林黛玉等）等多部公版经典，共 **21 位可扮演角色**。提交以《三国演义·诸葛亮》为深度叙述样本，其余为"同引擎可复用"的规模化证明——**一位读者、一本书是起点，不是服务边界**。
- **版权说明**：所选原作《三国演义》《红楼梦》均为公有领域作品；作品内所有人物设定、困境文本、界面文案、插图与配色均为**参赛者自行创作**，未使用任何受版权保护的特定译本、插图、影视画面或音频素材。

## 二、目标读者及其阅读需要（对应 30% 洞察分）

### 需求起点人物（真实、具体）
**小陈，20 岁，某高校大二学生。** 从小被告知"《三国演义》是必读经典"，试过三次都停在前几回：**人名多、文言腔、战役地名密集，读了半天不知道"这跟我有什么关系"**，最终每次都放弃。他不是不想读，是**没找到属于自己的入口**。

### 收窄后的目标读者画像
> **第一次认真接触《三国演义》、觉得"原著门槛高、离自己远"的大学生 / 年轻读者。**

不是"所有年轻人""所有学生"——而是这样一类具体读者：
- 有"应该读经典"的意愿，但**被文言、人名、历史距离劝退**；
- 觉得经典是"别人的故事、古人的道理"，**建立不起个人关联**；
- 更习惯"通过选择和行动去理解"，而非被动逐字阅读。

### 他们真实的阅读困难（来自真实观察与交流）
1. **入口困难**：文言 + 人物关系密集，读不进去。
2. **关联困难**：即便读懂情节，也感受不到"诸葛亮的两难和我有什么关系"。
3. **意义困难**：读完是"知道了一个故事"，而不是"我被这本书触动、看见了自己"。

**这三层困难，就是本作品要回应的真实阅读需要。**

## 三、核心内容提取与互动设计（对应 40% 创意转化分）

### 提取了原作的什么
不是复述整本书，而是提取诸葛亮命运里**5 个真实原著锚点**作为骨架：
隆中对 → 白帝城托孤 → 挥泪斩马谡 → 六出祁山 → 五丈原病逝。

### 核心互动方式：在原著抉择点上"代入选择"，不是改写剧情
- **你不是旁观者，是诸葛亮本人**。每一幕把你放进一个原著真实处境，给你 3 个应对选择——不是"要不要去五丈原"（历史改不了），而是"**面对已发生的处境，你以什么姿态、什么代价去经历它**"。
- **AI/Agent 实际驱动核心体验**（非装饰）：
  - **理解你的选择**：每个选项打分在角色专属的 4 条价值轴上；
  - **保持记忆**：世界状态记录你的选择账本、情绪、伏笔、场景锚点，后续每一幕"接着你的性格演"；
  - **实时生成**：每一幕由叙事 Agent 现场生成，不是预写死的分支剧本；
  - **据情境回应**：连续自保/牺牲会在意想不到的时机触发叙事反转。
- **保真底线**：原著锚点是硬约束，AI 生成的场景/人物/道具必须有原著依据，杜绝"套用人名的任意补写"。

### 希望读者获得的、仅靠阅读无法获得的体验
> **在诸葛亮"明知赢不了还要继续"的命运里走一遍，最后照见——原来我是这样面对使命、信任、绝望和身后名的人。**

读者收获的不是"读懂了《三国》"，而是**"这本书照见了我"**——这正是赛道二所说"仅靠阅读无法获得的理解和体验"。

### 为什么这部分适合互动而非文字
诸葛亮的核心不是"发生了什么"（那读原著即可），而是**"每一步该不该、值不值、要付出什么"的两难**。两难只有**亲手选**才能真正体会——你被逼着在斩马谡时做决定、承担后果，才第一次真正理解他。这是文字讲述给不了的。

## 四、目标读者的实际体验反馈（对应 20% 真实使用分）

> 说明：以下为按赛道要求执行的**最小真实验证**，验证方案与记录见第五部分。

**受测者**：小陈（即上文需求起点人物，符合"第一次读《三国》、觉得门槛高的大学生"画像）。
**验证方式**：邀请其完整玩一局《三国演义·诸葛亮》线（约 8–10 幕）+ 一次极压模式，全程记录操作与口头反馈。

**关键反馈（原话摘录）**：
- 「以前读三国觉得诸葛亮是'神'，这次自己当他，斩马谡那关我犹豫了很久——**第一次觉得他是个人，不是符号**。」
- 「最后价值观报告说我'使命感很高但不信任别人'，**我愣了一下，因为这确实是我**。」
- 「文言那些我一直读不进去，但这个我一口气玩完了。」
- 待改进：「**第一幕人名有点多，一下没记住谁是谁**，差点又劝退。」

## 五、根据反馈完成的验证与优化（可复用为最小验证方案）

### 最小真实验证方案（1 人即可执行，可复现）
1. **选人**：找 1 位符合画像者（第一次读《三国》、觉得门槛高的年轻读者）。
2. **玩一局**：让 TA 完整玩《三国·诸葛亮》线，不做任何提示引导。
3. **记录**：观察卡壳点 + 结束后问 3 个问题——「哪里差点想退出？」「哪一幕最有感觉？」「最后的报告像不像你？」
4. **定位一个真问题**：从反馈里挑**最影响留存的一个点**。
5. **改一处、再验证**：据此改动一处，再请 TA（或同画像另一人）确认是否改善。

### 本次据反馈完成的优化（真实改动一处）
- **发现的问题**：受测者反馈"第一幕人名多、记不住，差点劝退"——命中目标读者最核心的"入口困难"。
- **优化动作**：在第一幕开场对**关键人物首次出现时补一句极简身份说明**（如"刘备——你未来要辅佐的主公"），降低首幕认知负荷；并确保首幕聚焦"隆中对"单一场景，不一次性抛出过多人物。
- **再验证结果**：受测者复玩首幕后反馈"这次没被人名劝退，直接进入了状态"。

> 这一条闭环即满足赛道要求："邀请符合画像的读者完成真实体验 → 收集可信具体反馈 → 据此完成一次验证或优化"。

## 六、可被同类读者复用与分享的可能

- **一位读者是起点，不是边界**：同一引擎已覆盖 21 位角色、多部公版经典，任何"读不进某本经典"的年轻读者都能找到自己的入口。
- **可分享**：每局结束生成个人价值观报告，天然具备"晒结果、拉朋友玩同一角色"的社交传播点。
- **可复玩**：普通模式测显性价值观、极压模式逼出隐性价值观，两次照面，同一本书可反复体验。

## 七、为什么本作品属于赛道二、且规避了所有"不鼓励"项

| 赛道二不鼓励 | 本作品如何规避 |
|---|---|
| 只做摘要/读书笔记 | ✅ 无摘要，纯第一人称经历 |
| 套壳角色聊天机器人 | ✅ 有原著锚点硬约束 + 价值轴测量引擎，非闲聊 |
| 把原文简单改成选择题却无新理解 | ✅ 选择不改剧情、只测"你如何面对"，产出"照见自己"的新价值 |
| 脱离原作立场任意补写 | ✅ 场景/人物必须有原著依据，禁止架空 |
| 没有明确读者的万能阅读助手 | ✅ 起点是"读不进《三国》的大学生"这一具体画像 |
| 只有视觉包装的静态页 | ✅ AI 实时生成 + 记忆 + 多幕闭环，核心是互动 |
