# 价值说明 · 难得读书的设计哲学

> 这不是一份功能清单，而是这款产品「为什么这样设计」的说明书。
> 全部原则都对应代码里的真实实现，可在 `src/lib/agent/` 与 `src/app/api/narrative/` 中逐条核对。

我们的核心命题只有一句：

> **在不预设「什么是对的」的前提下，帮一个人发现自己的价值观；再用极限施压，逼出他连自己都没意识到的深层价值观；最后让两次的自己照面。**

下面把这句话展开成 17 条设计原则（外加一个记录未落地构想的「🚧 构想区」）。每条都讲清三件事：**关照哪些维度、背后有哪些考量与取舍、以及代码里具体怎么做到的**——思路在前，实现在后，均可对照源码核对。

---

## 🔎 速览：价值观 & 困境（最新版）

> 这一节是全篇最核心两块的浓缩，方便一眼看清现状；细节见原则六、十二、十四。

**一、价值观——8 条元价值轴（跨角色通用、彼此正交）**

| # | 轴名 | 衡量什么 |
|---|------|---------|
| 1 | 规则感 | 服从外部规则 ↔ 相信自己的判断 |
| 2 | 自我优先度 | 保全自己 ↔ 牺牲自己 |
| 3 | 连接需求 | 依赖情感连接 ↔ 独立自足 |
| 4 | 风险承受 | 保守规避 ↔ 冒险出手 |
| 5 | 身份锚点 | 依赖外部评价 ↔ 依赖内部标准 |
| 6 | 真实代价 | 为真实付代价 ↔ 维持表面平静 |
| 7 | 享乐克制 | 即时满足 ↔ 长远自律 |
| 8 | 理性感性 | 逻辑计算 ↔ 情感直觉 |

为什么恰好 8 条：这几条**彼此正交**，任何选择都能投影到它们上量化（如同红绿蓝三原色能调出所有颜色）。参照大五人格 / 道德基础理论 / 施瓦茨价值观理论——"少数正交维度即可覆盖无限情境"。再多加就会与已有轴重叠（如"利他↔利己"已被"自我优先度"覆盖），属冗余。角色专属的四轴每局现生成，靠关键词自动映射到这 8 条元轴，实现跨局可比。（对应 `world-state.ts` → `META_AXES`）

**二、困境——81 条结构化两难，运行时才与角色拼装**

- **8 大场域**：感情关系(14) / 职场权力(11) / 禁忌诱惑(10) / 背叛信任(10) / 家庭代际(9) / 身份认同(9) / 生存底线(9) / 命运偏爱(9)，共 81 条。
- **选项与困境绑定**：每幕抽 1 个困境，AI 拆成 3 个**同一困境的价值排序解法**——甲保全 / 乙折中 / 丙最重代价，强制**势均力敌、无明显正确答案**，堵住"挑最划算的"逃避表态。
- **贴合度加权**：`selectDilemmas` 先按角色场域粗筛，再用角色的核心伤口 / 在保护什么 / 最怕失去，与候选困境做 bigram 关键词打分（`affinityScore`），**优先抽最戳这个角色的困境**。
- **新角色同样吃到匹配**：用户自定义角色（AI 现生成 DNA）走 `driveAnalysis`，同样拼成贴合度文本，不退回随机。

> 一句话：**8 条正交价值轴是坐标系，81 条困境是投进坐标系的题目**——困境负责"够戳、够现代、贴合这个角色"，价值轴负责"让你的每次选择都能被量化、跨局比较"。

## 🏛️ 原则的三层效力结构与冲突仲裁（宪法思想）

> 原则不该是一张"看起来都一样重"的平铺清单。原则里有的违反了产品当场失去存在合法性（欺诈、版权、核心命题崩塌），有的只是体验差一点。我们像宪法那样，给它们**分效力层级**，并规定冲突时的**让步顺序**。这不只是文档表述——它已落到代码：`narrative-principles.ts` 的 `PROHIBITIONS` 每条带 `tier` 标签，`buildProhibitionsBlock()` 按 L1→L2→L3 排序注入每一幕 prompt，红线永远排在最前、最先被 AI 看到。

**先分出「方法论」与「设计律」两类**：元原则「反向产品化」（见开篇）讲的是**我们怎么迭代**，不是**设计对错的判据**，它不参与下面的层级仲裁，单独作为方法论存在。以下分层只针对"设计律"（原则零～十八）。

**三层效力（判据 = 违反它的后果有多严重）**：

| 层级 | 含义 | 违反的后果 | 包含的原则 |
|------|------|-----------|-----------|
| **L1 · 宪法级红线** | 不可违背 | 产品失去存在合法性（欺诈用户 / 版权风险 / 核心命题崩塌） | 原则零（原著诚实）、原则一（价值中立）、原则二＋十三（行为累积＋两次分析＝产品心脏）、**原则十八（既定事实锁定）** |
| **L2 · 核心体验支柱** | 尽力守住 | 还是这个产品，但体验会残 | 原则三（极压）、四（锚点）、五（两次对比）、六（元价值轴）、九（现代重看）、十二（抉择三件套＋等权） |
| **L3 · 实施级手艺** | 可迭代修 | 局部粗糙 | 原则七、八、十、十一、十四、十五、十六、十七 |

**冲突仲裁顺序（核心规则）**：任意两条原则冲突时，**低层永远为高层让步（L1 > L2 > L3）**。几个已在代码中生效的实例：

1. **既定事实（L1·原则十八） vs 原著默认剧本（L1·原则零）**：当玩家的合法选择使剧情偏离原著（如派魏延守街亭并守住），二者会正面冲突。仲裁规则是——**原则零保真的是"未被玩家改动的骨架"，被玩家合法改动的部分以既定事实为准**。所以此时绝不能再出现"马谡失街亭 / 斩马谡"。（代码：`world-state.ts` 的【已成定局·不可推翻的事实】块 + `init/route.ts` 的【铁律·承接既定事实】）
2. **自由决策（L3·原则七） vs 原著保真（L1·原则零）**：玩家想让林冲去谈恋爱这种"改骨架"的自由，被 L1 拦下——自由只作用于"视角/心态/代价"，不作用于"事件骨架"。
3. **戏剧弧线（L3·原则十一） vs 价值中立（L1·原则一）**：为了戏剧张力也不能暗示某个选择更正确——中立优先。

> 一句话：宪法不是靠"条文少"来保证权威，而是靠"效力等级 + 冲突时听谁的"。我们不删不并原则（每条都锚定真实代码，删了就丢了"为什么这么写"的记忆），而是**分层**——让红线永远压过手艺。

## 为什么「原则设计」才是这款产品的真正内核

**请把这份文档当成产品本体的一部分，而不是附录。** 一个测价值观的产品，最容易被误解为"一堆好看的界面 + 一个会写字的大模型"。但如果只有界面和模型，任何人都能在一周内复刻一个"看起来像"的版本——它会给出结论、会煽情、会用漂亮的句子夸你，然后**测出的东西是失真的、结论是可疑的、体验是一次性的**。

真正让这款产品"测得准、逼得出、经得起复玩"的，不是任何单一功能，而是**贯穿始终的一整套原则设计**。原则在这里承担三件别的东西替代不了的事：

1. **原则是产品的"骨相"，功能只是"皮相"。** 中立（原则一）、行为累积而非问卷自陈（原则二）、每个选项都是测动机的"三件套"（原则十二）、两次分析才测得出价值观（原则十三）——这些决定了"测出来的到底是不是你"。没有它们，界面再精致，结论也只是大模型的即兴表演。**皮相可以抄，骨相抄不走。**

2. **原则是约束 AI 的"硬缰绳"，而不是对 AI 的"许愿"。** 极限施压的证据驱动、锚点的正反例、戏剧弧线的硬约束、分支的规则触发、代价的关系反噬——每一条都把"希望 AI 表现好"翻译成了"AI 不这么做就过不了"的代码级约束。**产品的稳定性，恰恰来自这些原则被写死成硬约束的部分（见文末🟢/🟡/🔴自评）；越是只靠 AI 单次发挥的地方，越不可靠。** 原则设计的水平，直接决定了这款产品的下限。

3. **原则是护城河，也是这款产品"为什么值得存在"的答案。** 同类产品的差距，从来不在"用了哪个模型"，而在"对'如何不带偏见地测出一个人'这件事，想得有多深、并把多少想法真正落进了约束里"。这 17 条原则 + 反向产品化方法论，就是这份"想得多深"的完整记录——**它既是设计说明，也是这款产品最难被复制的资产。**

> 一句话：界面和模型决定这款产品"看起来像什么"，而原则设计决定它"到底是不是那个东西"。读完下面 17 条，你会明白：删掉任何一条，产品都会悄悄退化成一个"会算命的聊天框"。

## 元原则（方法论）：反向产品化——先做，再提炼原则，再用原则反推产品

**这套文档不是"先写原则、再照着做"的产物，恰恰相反。** 它是一个反向的、并且不断循环的过程：

```
先动手做（凭直觉/灵感/大规划做出一版）
   │
   ▼
从已做出的东西里，提炼、命名、串成"原则"
   │
   ▼
把原则当成一把尺子，反过来量产品：哪条落地强、哪条只是嘴上漂亮
   │
   ▼
照着"没兑现的原则"反向改产品 —— 让体验追上原则
   │
   └──────────────► 再提炼 → 再反推（闭环，持续进行）
```

**为什么这套方法新颖、也更诚实**

1. **和常规顺序相反**：绝大多数产品是"先立原则 → 再实现"。我们是"先实现 → 再提炼原则 → 再用原则反向优化实现"。原则在这里不是**起点**，而是**从实践里长出来、又回过头去校准实践的工具**。
2. **它天然自带"打假"能力**：一旦把模糊的直觉写成清晰、锋利的原则，"原则写得漂亮、体验却没兑现"的落差就会**暴露无遗**。原则越锋利，越能照出产品还差在哪——这正是我们能诚实盘点"哪几条落地强、哪几条弱"的原因。
3. **它把"感慨"变成"路线图"**：好的设计文档应当比当前产品**略微超前**——它描述的是"这个产品成熟后该有的样子"。于是"原则震撼、体验平淡"不再是尴尬，而是一份**待办清单**：每一条落地弱的原则，都是一个明确的改进方向。
4. **闭环，而非一次性**：提炼出的原则会指向新的改动，改动完成后又可以提炼出新原则（比如本条元原则，以及原则十七"选择→反馈闭环"，都是在反复讨论与复盘中"长"出来、再补回文档的）。

**这套方法的一次真实运转**（可在 git 历史中核对）：我们先盘点出"锚点/时空折叠/极压"这几条**原则漂亮但落地弱**，随后针对性地反向改产品——给锚点加正反例把"通用废话"逼成"只属于这一局的话"、让极压"证据驱动"地回指你上一局做过的具体的事、把"算了却从未展示"的元价值轴画到结果页、并给内容库扩容。**每条改动都对应着某条原则的"落地补强"**——这就是"反向产品化"的一次完整闭环。

> 一句话：我们不是先有原则再有产品，而是让产品先长出来、把它提炼成原则、再用原则回头逼产品变得更好——原则是镜子，照的不只是玩家，也是我们自己。

> 关于各原则当前的落地强度（🟢 真落地 / 🟡 骨架强血肉靠 AI / 🔴 高度依赖 AI 单次生成），见文末【附：各原则落地现状自评】——我们诚实地标出来，因为这正是"反向产品化"下一轮要盯的地方。

## 原则零（保真底线，统领全篇）：原著诚实——有就是有，没有就没有

> 这是一条比其余所有原则更底层的**诚信底线**：我们可以用现代价值观拆解原著、可以把原著情节做成故事锚点、可以在锚点之上由 AI 演绎未写尽的内心与细节——**但一切演绎的「基础材料」必须忠于原著本身。原著有的才用，没有的绝不编造。**

**目标**：让玩家清楚地知道——他体验到的"骨架"（关键情节、人物、结局）是原著真实的，只有"血肉"（内心、动机、未写细节）才是代入演绎。绝不让系统在自己并不了解一本书时，硬编出一个看似煞有介事、实则子虚乌有的"伪原著"。

**关照哪些维度，为什么这么设计**：用户曾反馈"感觉 AI 没读过这本书"——根源在于对**未收录的冷门书**，系统曾在没有任何原著数据时靠模型记忆硬编，幻觉失控。我们区分两类"偏离原著"：
- **弹性演绎（保留）**：原著没细写的内心/动机/对话——这是"代入体验"的核心，不是幻觉；
- **事实硬伤（消灭）**：错人名、错事件、编造原著没有的重大情节或结局——这是必须治的真幻觉。

用户会因为一处硬伤而全盘否定（连合理演绎也误判成幻觉），所以底线是：**守住弹性演绎，消灭事实硬伤。**

**代码里具体怎么做到的**（`init/route.ts`）：
1. **预设 21 位角色**：人工校订的 `canonicalMoments` 原著锚点 + "必须保真、不得架空"的 prompt 硬约束——保真度最高。
2. **自定义书临时生成 DNA**：让 AI 分析角色时**一并生成 3–5 条原著锚点与置信度**，并同样注入保真约束（标注"由 AI 依据原著理解生成，仍须严格围绕、不得再另编重大情节"）。生成的锚点挂到 `WorldState.canonicalMoments`，后续每一幕复用。
3. **诚实回退（关键）**：AI 若判定自己**不认识这本书/角色或无法确认其真实存在**（`known:false`），系统**立即停止、不硬编**，诚实提示用户换一本更知名的经典或从推荐书目开始。
4. **低置信透明告知**：`confidence` 过低时，返回 `lowConfidence` 标记，前端提示"以下情节为 AI 推测，可能与原著有出入"——不阻断，但不欺瞒。

> 一句话：**基础材料终于原著，有就有、没有就没有；演绎可以自由，编造绝不允许。** 这条底线在，用户才敢信我们端上来的"骨架"是真的。

**补充·关于"忠于哪个版本"的立场**：一本书往往有多个校勘本、译本。我们的立场是——**忠于原著广为公认的核心情节骨架，而非某一特定校勘本或译本的字句**。
- **只锚定跨版本共识**：不管读哪个版本的《三国》，诸葛亮都经历隆中对、斩马谡、病逝五丈原——我们锚定的正是这些所有版本共有的关键情节。
- **刻意不复述原文、不引用任何译本字句**：我们做的是"情境代入"而非"文本还原"。这样既绕开不同校勘本/译本的版本争议，也规避了特定译本、插图等受版权保护素材的风险（呼应赛道版权要求）。
- **续写争议的诚实边界**：涉及有续写争议的作品（如《红楼梦》后四十回、黛玉焚稿断痴情等属程高本续写），采用**最广为流传的通行本叙事**——因为那是绝大多数读者认知里的版本；被问及时如实说明，不含糊。

> 所以"忠于哪个版本"对我们不构成软肋：我们忠于的是**所有版本共有的那个故事内核**，且不碰任何特定版本的具体文本。

## 原则一：中立——我们不预设任何价值观倾向

**目标**：玩家的选择不能被我们「引导」到某个我们认为更高尚的答案。一旦有标准答案，测出来的就不是玩家的价值观，而是玩家对「正确答案」的揣摩。

**关照哪些维度，为什么这么设计**

一个测价值观的产品，最大的敌人是它自己的偏见。只要设计者暗中觉得某个选项"更好"，整套结果就失真了——玩家会去揣摩"你想要的答案"，而不是暴露"自己真实的排序"。所以"中立"不是一句姿态，而是要从三个入口同时堵死"标准答案"：

- **语言入口**：叙事的措辞不能夹带褒贬。点破语、内心独白都必须是"这个人此刻真实会想的"，而不是道德表态——一旦出现"他终于做出了正确的选择"这类词，暗示就产生了。
- **结构入口**：选项之间必须是"排序不同"而非"对错不同"。三个选项每一个都能自圆其说（自私的、仗义的、和稀泥的都合情合理），玩家才敢"认领"真实的自己，而不是被道德感绑去选那个"看起来对"的。
- **起点入口**：每个人进入时的价值坐标必须绝对居中，不预置任何倾向。倾向只能是他自己一步步走出来的，不能是我们贴上去的。

**背后的考量与取舍**

1. **为什么连"结局"都不评判**：如果过程中立、结局却奖惩，那中立就是假的。所以结局只描述"你走到了哪里"，既不惩罚也不表扬——否则玩家下一局就会为了"好结局"而表演。
2. **为什么宁可牺牲"爽感"也要去掉正确答案**：有明确正确答案的选择题更有即时爽感（"我选对了"），但那一刻测的就不再是价值观，而是智商测验。我们主动放弃这种爽感，换取结果的真实。
3. **为什么要把中立写成硬性禁令、而非提示**：AI 生成时天然倾向于"教育"玩家、给正能量结尾。只有把"禁止暗示对错"固化成每幕强制注入的铁律，才能压住这种漂移。

**怎么做到的（对应代码）**：

1. **写进「宪法」的铁律禁令**（`narrative-principles.ts` → `PROHIBITIONS`）。每一幕生成时都强制注入这几条禁令，其中第一条就是：
   - *「不能有标准答案，不能暗示某种选择更道德或更正确」*
   - *「点破语必须说人话，不评判对错」*
   - *「内心独白必须赤裸真实，是这个人在那一刻真实会想的，不是道德表态」*
2. **三选项等价设计**（`init/route.ts` 的幕生成要求）：明确要求*「三个选项代表不同价值排序，没有明显优劣」*。选项之间是价值排序的差异，不是对错的差异。
3. **初始分值绝对居中**（`world-state.ts` → `createWorldState`）：所有价值轴初始都是 `50` 分（0–100 区间正中）。我们不给任何人一个预设的「起跑倾向」，倾向完全由他自己的选择累积而来。
4. **结局也不评判**（`ENDING_PRINCIPLES`）：*「结局不是惩罚也不是奖励，是选择累积的自然延伸」「用照镜子的语气，只描述他走到了哪里，不评价对错」*。

> 一句话：我们只提供处境，不提供答案。系统全程用「镜子」的语气，而不是「裁判」的语气。

## 原则二：发现价值观——用「行为累积」而不是「问卷自陈」

**目标**：不问「你是否重视忠诚（1–5 分）」这种问卷题——人对自己的自陈往往是他想成为的样子，而非真实的样子。我们要从**行为**里读出价值观。

**关照哪些维度，为什么这么设计**

价值观不是问出来的，是在一次次两难里"漏"出来的。所以这一原则关照的核心，是"如何绕过人的自我美化，从行为里读出真相"：

- **专属维度，而非通用问卷**：每个角色用一套"贴着他处境"的价值轴（如林冲的"忍耐极限/尊严底线"），而不是一套放之四海的通用问卷。因为脱离具体处境的抽象提问（"你重视忠诚吗"）只会得到人人都给的正确答案；只有把选择嵌进具体的两难，倾向才藏不住。
- **隐藏计分，而非显性打分**：玩家全程看不到分数，只看到剧情。因为一旦让人看见"这个选择加 10 分忠诚"，选择立刻变成刷分游戏，测的就不再是价值观。
- **模式，而非单点**：我们看的不是某一次选择，而是"反复怎么选"。连续三幕自保和偶尔自保一次，含义天差地别——单点是噪声，模式才是信号。

**背后的考量与取舍**

1. **为什么不用问卷/自评**：人对自己的自陈，往往是"想成为的样子"而非"真实的样子"。行为会说谎得少得多——尤其当行为要付出代价时。
2. **为什么要让分数隐藏、让代价显性**：我们刻意把"分数"藏起来、把"选择的代价"摆出来。让玩家权衡的是剧情里的得失，而不是屏幕上的数字——这样他的选择才诚实。
3. **代价**：隐藏计分意味着玩家中途没有"进度条"式的即时反馈，可能少一点游戏感。我们认为这个代价值得——因为可见的分数会立刻污染测量本身。

**怎么做到的（对应代码）**：

1. **每个角色一套专属价值轴**（`character-dna.ts` / AI 动态生成）。比如同一套四轴可能是「忠诚代价 / 忍耐极限 / 尊严底线 / 时机判断」，是从这个角色的原著处境里长出来的，而不是一套通用问卷。
2. **每个选项携带隐藏打分**（`init/route.ts` 的 `scores` 字段）。玩家看到的是剧情选项，看不到分数；选下去后，`applyChoice`（`world-state.ts`）才把该选项的 `scoreDelta` 累加到对应轴上，并夹在 0–100 之间。
3. **行为计数器**：`applyChoice` 同时维护 `consecutiveSelfPreserve` / `consecutiveSacrifice`（连续自保/牺牲次数）。价值观不是单次选择，而是**模式**——连续三幕都自保，和偶尔自保一次，含义完全不同。
4. **结论从统计里长出来**（`ending-narration/route.ts`）：结算时统计 A/B/C 的比例、是否后期转向（`hasLateReversal` 正则检测选择序列）、是否每次都走极端、是否触发过陷阱……这些**行为事实**才是结论的证据，而非玩家的自我描述。

> 一句话：你说你是谁不算，你在一个个两难前实际选了什么，才算。

## 原则三：极限施压——逼出「深层价值观」

**目标**：常态下人人都能表现得体面。真正的价值观是「当代价高到无法承受时，你最后守住的是什么、最先放弃的是什么」。极压模式就是为此设计的压力测试。

**关照哪些维度，为什么这么设计**

常态下的选择藏着很多余地，人可以"和稀泥"地维持体面。真正的价值排序，只在"什么都要失去"的绝境里才现形。所以极压这一轮关照的，是"如何制造一个无处可躲的绝境，逼出底线"：

- **代价维度**：把每个困境的代价从"可承受"抬到"不可逆"。有回旋余地时，人会选那个"既不太亏又显得体面"的中间项；只有代价永久时，他才被迫亮出真正的优先级。
- **时间维度**：普通局压力缓慢爬升，极压局压力从第一幕就压顶、且幕数更短。因为极压不是要"讲一个更长的故事"，而是要"最快地逼出那个决定性瞬间"。
- **针对性维度（关键）**：极压不是无差别加压，而是**冲着你普通局暴露的软肋去**。泛泛的生死抉择测不出个体差异；只有专打"你最在乎/最想保护的那个东西"，才逼得出这个人独有的底线。

**背后的考量与取舍**

1. **为什么是"再玩一次同一个角色"，而不是直接把第一局做难**：必须让常态局先跑完、拿到"舒适区人格"的基线，第二局的落差才有意义。两局对照本身就是产品的核心洞察（见原则五），所以极压必须是独立的第二轮，而不是把第一轮调难。
2. **为什么极压要"读第一局数据"再施压**：如果两局用同一套随机困境，对比就只是"运气不同"。只有让极压精准复用你第一局的软肋，落差才能干净地归因于"压力"，而不是"题目变了"。
3. **代价与风险**：极压的强度可能让人不适。我们的底线是——代价再重，也必须是"你过往选择合乎逻辑的反噬"（见原则十六），而不是系统凭空的惩罚。逼到墙角可以，但不作弊、不审判。

**怎么做到的（对应代码）**：

1. **困境强度分级**（`dilemma-library.ts` → `intensity: 1|2|3` + `extremeVersion`）。每个困境都写了普通版和「极端版」两套文案。普通局 `dilemmaIntensity = 1`，极压局直接 `= 3`，并优先使用 `extremeVersion`。
2. **全程无软着陆**（`init/route.ts` → `intensifyBlock`）：极压模式强制注入*「每幕困境必须直接升级到生死抉择或无法挽回的背叛，没有先忍忍的选项，没有软着陆。三个选项的代价都是永久性的，只是方向不同」*。
3. **压力从第一幕就来**：普通局的不可逆「陷阱选项」要到第 3 幕后才允许（`isTrapAllowed = actNumber >= 3`），极压局第 1 幕就允许（`>= 1`），且总幕数缩短到 6 幕（`maxActs = 6`）——聚焦、密集、高强度。
4. **多元价值画像 + 逐幕分型施压（核心·已升级）**（`value-profile.ts` → `buildValueProfile` / `buildIntensifyDirectiveForAct`，由 `init/route.ts` 与 `next-act/route.ts` 逐幕调用）：极压不再只挑"最暴露的一次"做单点回指，而是**先把普通局拆成三类价值画像，再让极压三幕分别把每一类推到极限**：
   - **【主流值】**：高频一致、反复坚持的主导价值（你最硬的那个）；
   - **【隐性值】**：低频但在关键节点（越靠后的幕 / 极端选项 / 与主流相反的方向）刷出的隐藏价值（你以为自己不在乎、其实会痛的那面）；
   - **【矛盾/困惑值】**：同一处境类型下前后选择自相矛盾、反复横跳的摇摆点。
   - 三类画像**逐幕对准下发**：**第1幕【砸·主流值】**（让你最坚持的价值直接反噬）→ **第2幕【逃·隐性值】**（专戳那根你以为不痛、其实会痛的隐线）→ **第3幕【撞·矛盾值】**（把你摆摆不定的那一对直接对撞，逼你亲手裁决"到底哪个才是真正的我"）。服务端按 `actNumber` 只下发当前这一幕对应的那一层，施压真正做到"逐幕对准"。

**深度剖析：极压如何用"多元价值画像"设计"分型施压"的三幕**

这是极压模式真正精巧的地方——它不是把同一批困境调难重播，也不再只盯着"一个软肋"打，而是**先把你第一局的价值观识别成三层（主流 / 隐性 / 矛盾），再让三幕分别验证每一层**。我们要发现的不是单一执念，而是一个人**多元的、甚至他自己都不易察觉的价值**：

- **第1幕·砸主流**：识别你反复坚持、出现频次最高的那类价值，用不可逆情境让它反噬——**你越坚持，越快失去你最在乎的东西**，逼你看清坚持的真实代价。
- **第2幕·逃隐性**：这一层最微妙。算法专门去找那些"低频、却在关键时刻（越靠后的幕、极端选项、与主流相反的方向）冒出来"的选择——它们往往是你**自己都没意识到的价值**。第2幕就制造一个只有触到这根隐线才会痛的处境，让你**猝不及防地发现"原来我在乎这个"**。
- **第3幕·撞矛盾**：如果你在某类处境上反复横跳（一次自保、一次成全），说明这里藏着你真正的**困惑**。第3幕把这对矛盾直接对撞，设计一个无法再骑墙的终局，**把困惑逼成答案**。

**为什么要"分型施压"而不是"单点狙击"或"统一加难"**：统一加难只能测出"你抗不抗压"；单点狙击只能验证"你最明显的那个软肋"。只有把价值观拆成主流 / 隐性 / 矛盾三层、每一层各用一幕去验证，才能一次极限体验里**同时照出你的主流、你的盲点、和你的困惑**——这才对得起"发现用户多元价值"的初衷。三幕合起来，是对一个人价值观的一次完整极限验证。

> 一句话：极压模式不是把难度调高，而是把三台摄像机分别对准你在常态下藏得最好的三处——你最硬的坚持、你没察觉的在乎、和你自己都没想通的矛盾。

## 原则四：锚点设计——把结论变成「能照进现实的一面镜子」

**目标**：结论如果只是「你忠诚度很高」，那是一个标签，人看完就忘。我们要的是让人**在结论里认出自己**——所以我们把结论做成一个个「具体画面 + 一个自省问题」，叫它「价值锚点」。

**关照哪些维度，为什么是这几个**

一个人在一局里暴露出来的东西，不在同一个层面上，硬揉成一句话就会互相稀释。所以我们让锚点**从几个彼此独立的层面分别生长**，每个层面回答一个不同的问题：

- **行为层——你「怎么做」**：你反复自保、反复牺牲、还是一直和稀泥？后期有没有突然转向？行为模式是最外显、也最诚实的一层，因为它是你一次次真金白银选出来的，骗不了人。
- **价值取向层——你「更看重什么」**：在这个角色的专属价值维度上，你把哪一端拉到了极致。这一层回答的是「排序」——当两个都好的东西冲突，你先放弃谁。
- **底层心理层——你「为什么这么做」**：行为背后更稳定的倾向（规则感、连接需求、风险承受……）。这一层想穿透"这一局的具体剧情"，触到那个跨故事都成立的你。
- **情绪层——你「最后是什么状态」**：只有当收尾情绪足够鲜明（释然 / 绝望 / 愤怒 / 悲凉）才纳入。因为情绪是选择的余味，平淡时它不承载信息，强烈时它本身就是结论。

**背后的考量与取舍**

1. **为什么要分层，而不是给一个总结论**：价值观是立体的——「做了什么」「看重什么」「为什么」「什么感受」是四个不同切面。合并会得到一句正确的废话；分开，每一面才都锋利。
2. **为什么只挑"最偏"的那几条，还要控制总数**：全维度罗列等于没有重点，人会麻木。我们只保留**偏离中性最远、最能定义你这一局**的少数几条——宁可少而扎心，不要多而模糊。这是"洞察"和"报告"的区别。
3. **为什么锚点必须从"你这局真实发生的情节"里长出来**：通用比喻（「你像一座孤岛」）谁都能套，正因为谁都适用，所以对谁都无效。只有从你亲历的那个具体场景提炼的画面，才会让你"咯噔"一下——这是我们明令禁止通用比喻的原因。
4. **为什么给的是"问题"而不是"建议"**：一旦给建议，就等于我们替你判断了对错，"无倾向"就破功了（见原则一）。所以锚点的收尾永远是一个不含答案、不做评判的自省问题——把判断权留给你自己。
5. **多照见一层「结构」，而不只是「你」**：我们还会顺着你这一局真正踩过的困境，反查它背后的"结构性张力"（见原则五/十六），让锚点不仅问「这是不是你」，也让你看见「是什么样的处境把你逼成了这样」——避免把系统性的两难，误读成你个人的缺陷。

**怎么做到的（对应代码 `ending-narration/route.ts`）**

- **四层分组，互不合并**：行为层（反复自保/牺牲/走中间/后期转向/触发陷阱）、价值轴层（取偏离中性 50 分最远的 2 条专属轴，≥72 归高端、≤28 归低端）、元轴层（偏移 ≥12 分的底层维度，见原则六）、情绪层（仅释然/绝望/愤怒/悲凉时纳入）。
- **每层单独出一个锚点，总数上限 4 个**（`finalGroups = anchorGroups.slice(0, 4)`），保证不重复、不糊成一团。
- **字数与素材硬约束**：画面 ≤20 字、自省问题 ≤25 字，且强制从本局真实情节生长、`prompt` 明令禁止通用比喻；`question` 不含答案、不做评判。
- **结构性张力反查**：用玩家踩过的困境反查困境库 `modernTension` 字段（如*「当服从被包装成职业素养，个人的道德判断就被系统性剥夺了」*），去重后独立成块。

> 一句话：锚点不告诉你答案，它只把你亲手走过的那一幕，端到你面前问一句「这是不是你」。

## 原则五：两次价值观对比——让「常态的你」与「极限的你」照面

**目标**：单独一局只能看到一个截面。把普通局和极压局并排，才能看到「压力到底改变了你什么、又没能改变你什么」——后者才是真正的底线。

**关照哪些维度，为什么这么设计**

一次分析只能给你一个截面；只有把常态局和极压局并排，才能读出"压力改变了你什么、又没能改变什么"。所以对比页关照的，是"如何让两局的落差被干净、公平地读出来"：

- **一致性维度**：两局都选一样的地方——这是你真正的底线，压力都撼不动的部分。
- **翻转维度**：两局选择相反的地方——这是你的"体面成本"，常态下装得住、绝境下装不住的部分。这一维度往往最有启发。
- **量化维度**：不止说"变了"，还要说"在哪条价值上、变了多少、往哪个方向"。模糊的"感觉不同"没有说服力，可读的偏移才有。
- **叙事维度**：在所有差异里，锁定"最大的那一个分岔点"，把抽象落差落到一个具体时刻——因为人记住的是瞬间，不是数据。

**背后的考量与取舍**

1. **为什么"没变"比"变了"更重要**：大多数产品只夸差异。但我们认为"压力都没能改变的选择"才是一个人真正的底线，所以代码里专门对"两局一致"给出肯定判定——它不是"没信息"，它恰恰是最硬的信息。
2. **为什么要用"同一把标尺"呈现（见原则十五）**：如果两局用不同刻度画图，落差会被视觉噪声吃掉。必须同轴、同刻度并排，落差才不骗人。
3. **为什么落差不做价值判断**：翻转不等于"你虚伪"，一致也不等于"你高尚"。对比页只呈现"距离"，把这段距离意味着什么，留给你自己解读——延续原则一的中立。

**怎么做到的（对应代码 `compare-narration/route.ts`）**：

1. **逐幕对齐 + 翻转检测**：同一幕位置，普通版选 A（自保）而极压版选 C（牺牲）——检测到这种相反选择即判定为 `hasFlip`（显著翻转）。
2. **三个层次的差异量化**：
   - **价值轴层**：`axesDiff` 逐轴算「普通分 → 极压分」的偏移，筛出变化 >10 分的轴。
   - **元轴层**：把两局分别映射到 6 个底层元轴，筛出偏移 >8 分的维度。
   - **执念层**：分别统计两局最频繁的社会焦虑标签，对比核心执念是否变化。
3. **据此判定「对比类型」**（`anchorType`）：转向型 / 自保型 / 牺牲型 / 越界型 / 底线型。
4. **旁白点出「分岔点」**：prompt 要求指出*「哪一个时刻是两个版本最大的分岔点」*，并给出一句「压力揭示的不是弱点，而是你的 ___」的桥接语。
   - 若两局取向一致 → 明确告诉玩家*「这是真正的底线」*；若翻转 → 指出*「他在压力下改变了选择」*。

> 一句话：常态的你是你想成为的人，极限的你是你实际是的人；对比页就是让这两个人握一次手。

## 原则六：跨局可比——「元价值轴」把不同角色的结果拉到同一把尺子上

**目标**：每个角色的专属四轴名字都不一样（林黛玉的轴和林冲的轴没法直接比）。但如果想比较「玩林黛玉的我」和「玩林冲的我」，就需要一套**跨角色通用的底层尺子**。

**关照哪些维度，为什么这么设计**

每个角色的专属四轴名字都不一样（林黛玉的"敏感"和林冲的"忍耐"没法直接比）。可玩家会自然产生一个诉求："玩了好几个角色的我，到底是个什么样的人？"要回答它，就需要一层"跨角色通用的底层坐标"：

- **专属轴负责"贴合"**：每个角色的四轴紧贴他的处境，保证代入时精准、不违和——这是"深度"。
- **元轴负责"可比"**：在专属轴之下，抽象出一套所有角色都能落进去的通用维度（规则感、连接需求、风险承受……），保证不同角色的结果能被放在一起看——这是"广度"。
- 两层并存：具体的四轴让你"入戏"，抽象的元轴让你"跳出来看自己的全貌"。

**背后的考量与取舍**

1. **为什么不直接用一套通用轴测所有角色**：那样会牺牲代入感——用同一把尺子量林黛玉和林冲，两个角色会变得面目模糊。深度和可比是一对矛盾，我们用"两层"来同时保住。
2. **为什么元轴是这 8 条（规则感/自我优先/连接/风险/身份/真实代价/享乐克制/理性感性）**：它们是心理层面相对稳定、且**彼此正交**、能跨题材成立的底层倾向——不管你玩的是官场、情场还是江湖，这几条都说得通。选轴的标准是「正交且完备」：大五人格 / 道德基础理论 / 施瓦茨价值观理论都指向"少数正交维度即可覆盖无限情境"（就像红绿蓝三原色能调出所有颜色）。所以是 8 条而非 20 条——再多加就会与已有轴重叠（如"利他↔利己"已被"自我优先度"覆盖，属于冗余）。
3. **代价**：从专属轴映射到元轴要靠"关键词匹配"，是一种近似而非精确换算，匹配不到时取中性值。我们接受这个近似——它的目的是"给出可比的大致画像"，不是"精确到分"。

**怎么做到的（对应代码 `world-state.ts` → `META_AXES` + `mapToMetaAxes`）**：

1. 定义 8 条通用**元价值轴**：规则感、自我优先度、连接需求、风险承受、身份锚点、真实代价、享乐克制、理性感性。
2. 每条元轴带一组**关键词**。用「关键词匹配投票法」把当前角色的专属四轴，映射并平均到这 8 条元轴上（匹配不到的轴取居中 50）。
3. 这样无论玩哪个角色，最终都能得到一份 8 维的、**可跨局横向比较**的价值画像——也是原则五里极压对比的量化基础之一。

> 一句话：专属四轴负责「贴合这个角色」，元轴负责「让不同的你能被放在一起看」。

## 原则七：主线情节 vs 用户自由决策——如何平衡

**目标**：既要让玩家有真实的自由（选择必须有后果、能改变走向），又不能让故事崩坏成脱离原著的胡编，还要保证叙事始终在「爬升—转折—收束」的戏剧曲线上。这是三方拉扯。

**关照哪些维度，为什么这么设计**

太自由，故事就散了；太固定，你就成了看客。这里要同时兼顾三个互相拉扯的维度，缺一不可：

- **戏剧维度（不能散）**：无论玩家怎么选，故事必须始终在"平静→升温→转折→收束"的曲线上，不能变成一盘没有节奏的流水账。
- **自由维度（不能假）**：玩家的选择必须真的改变后续——改变价值分值、情绪、埋下的伏笔，并被喂回给下一幕。否则"选择"就只是装饰，代入感立刻崩塌。
- **原著维度（不能飘）**：再自由，也不能让林冲跑去谈恋爱、诸葛亮改行经商。人物、场景、关键转折必须忠于原著（详见原则九、十四）。

**背后的考量与取舍**

1. **我们的核心比喻——"主线是铁轨，你控制的是车厢里的温度"**：我们不让玩家改变"发生了什么"（那是铁轨，由状态机和原著锚点焊死），只让玩家决定"在那件事里，你这个人怎么选、怎么想"（那是车厢里的温度，完全自由）。这条分界线，是整套平衡的支点。
2. **为什么骨架交给代码、血肉交给 AI**：戏剧节奏（第几幕、该起该转）是可被规则精确控制的，就交给状态机；而具体台词、心理、张力是需要创造力的，就交给 AI。各管各最擅长的，才不会失控。
3. **为什么收尾要"动态判定"而非固定幕数**：写死幕数会让有的故事硬凑、有的故事被砍。所以张力充分释放后允许 AI 自行收束——既不注水，也不烂尾。
4. **取舍**：这种"轨道内自由"不是无限自由——你无法改写结局走向。我们认为这是对的：产品要照见的是"你在既定命运里如何自处"，而不是"你能不能改命"。

**怎么做到的（对应代码）**：

1. **主线由「世界状态机」托底**（`world-state.ts`）：`WorldState` 用 `actNumber / maxActs` 推进幕次，并按比例自动切换叙事阶段「起→承→转→合→尾声」。无论玩家怎么选，戏剧节奏的骨架不会散。
2. **自由由「选择改变状态」保证**：每次 `applyChoice` 都会真实改写价值轴分值、追加选择历史、更新情绪基调、累积伏笔（`pendingTensions`）。选择不是装饰，它会改变后续每一幕的生成输入（`summarizeState` 把这些喂回 AI）。
3. **困境升级规则保证张力持续爬升**（`ESCALATION_RULES`）：
   - 第 3 幕起：至少一个选项代价不可逆（「永久失去」而非「麻烦」）。
   - 第 5 幕起：每个选择要和之前的选择形成因果连接，让选择产生「累积重量」。
   - 第 8 幕起：进入高压收尾，把所有未解张力一次逼上台面。
4. **叙事锚点保证跨幕连贯**（`narrativeAnchors`）：每幕产出 1–2 个具体场景细节（地名/人名/道具），下一幕强制引用其中至少一个，避免自由选择导致故事「断片」。
5. **收束条件动态判定**：AI 在张力充分释放后（通常 ≥8 幕）可自行把 `shouldContinue` 设为 false 收尾——既不硬凑长度，也不草草结束。

> 一句话：状态机管「故事往哪走、走到哪一段」，玩家的选择管「以什么姿态走过去、留下什么代价」。骨架固定，血肉自由。

## 原则八：分支策略——用「规则触发」代替「预写剧本树」

**目标**：预先写死的剧情分支树会指数爆炸，也僵硬。我们要让分支「因人而生」——根据玩家的行为模式，动态注入不同的剧情指令。

**关照哪些维度，为什么这么设计**

预先写死的剧情分支树会指数爆炸（10 个二选一就是 1024 条线），且僵硬、难维护。我们要让分支"因人而生"——不预存剧本，而是实时根据你的行为模式，动态给故事注入不同走向：

- **触发维度**：分支不是提前画好的地图，而是一组"条件→指令"。系统实时盯着你的行为（连续自保、某条价值轴拉到极端……），条件命中才注入对应的剧情反转。
- **一次性维度**：每种反转只触发一次。避免"你一自保、剧情就反噬"变成可预测的机械套路，保住惊喜感。
- **随机维度**：在满足条件的前提下，具体困境用"故事吸引力平方"加权随机抽取——精彩的更容易出现，但永远保留不确定性，让每一局都不一样。

**背后的考量与取舍**

1. **为什么用"规则引擎"而不是"剧本树"**：剧本树要穷举所有组合，写不动也改不动；规则引擎只维护十几条"什么情况该发生什么"，就能覆盖无穷多条实际路径。这是用"规则的有限"去撬动"体验的无限"。
2. **为什么反转要绑定"行为模式"而不是"单次选择"**：针对单次选择的反转太廉价、太可预测。只有当你"反复"表现出某种倾向，剧情才反噬——这样反噬才显得是"你自己招来的"，而非系统随机发难（呼应原则十六：代价要逻辑自洽）。
3. **为什么要保留随机性、而不是全按最优戏剧性来**：如果每次都挑"最精彩"的困境，重玩就会撞车、失去新鲜感。用"加权随机"而非"取最大"，是在"戏剧性"和"不可预测性"之间做的权衡——好故事更常出现，但不保证每次相同。

**怎么做到的（对应代码 `narrative-principles.ts` → `TWIST_RULES` + `buildPrinciplesPrompt`）**：

1. **反转规则是条件触发的**，不是写死的。每条规则带一个 `condition`，命中才注入对应指令，且多数 `onceOnly`（只触发一次，避免重复套路）：
   - 连续 2 次自保 → *「他一直在保护的那个东西，正在悄悄消失」*；
   - 连续 2 次牺牲 → *「他的牺牲被人当成理所当然，甚至被利用」*；
   - 尊严轴 >75 → *「保住尊严需要伤害一个无辜的人」*；
   - 忠诚轴 >70 → *「他忠诚的那个人做了让他无法辩护的事」*；
   - 忍耐轴 >72 → *「有人看穿他会忍，于是变本加厉」*。
2. **每幕动态组装指令**：`buildPrinciplesPrompt` 在每幕生成前，实时读当前分值和连续计数，把命中的反转规则 + 升级规则拼成一段「本幕特殊指令」注入 AI。
3. **困境加权随机**（`selectDilemmas` + `weightedSample`）：候选困境按 `storyAppeal²` 加权抽样——高张力困境更可能出现，但保留随机性，让每一局都不一样。
4. **主题偏好只做加权、不做硬塞**（`init/route.ts`，详见 README「忠于原著的主题匹配」）：所选主题只有和角色原著场域有交集时才提权，无交集则完全忽略。

> 一句话：分支不是提前画好的地图，而是一套「看你怎么走、再决定给你什么坎」的实时规则引擎。

## 原则九（贯穿全篇）：用现代价值观重看原著——精华所在

**目标**：这是整个产品的灵魂。古典名著的处境（招安、守节、尽忠、认命）用今天的眼光看，往往能被重新命名为一个当代人熟悉的结构性困境。我们要做的，是**在忠于原著情节的前提下，给古人的处境装上现代的解码器**，让玩家发现：他和林冲、和黛玉，其实困在同一种结构里。

**关照哪些维度，为什么这么设计**

这是整个产品的灵魂。古典名著的处境（招安、守节、尽忠、认命）用今天的眼光看，往往能被重新命名成一个当代人熟悉的结构性困境。我们要在"忠于原著"和"照见今天"之间，架一座三层的桥：

- **情节层（翻译处境）**：把古代困境翻成今天的具体场景——林冲的"忍上司欺辱"就是你的"职场 PUA"。让人先"看得懂"。
- **标签层（命名身份）**：给这个处境一个当代社会角色的名字（"沉默的共谋者""35 岁危机"）。让人"对号入座"。
- **结构层（点破系统）**：点出处境背后的社会机制（"当服从被包装成职业素养，道德判断就被系统性剥夺"）。让人"看清那个碾压你的东西不是你的错"。
- 三层叠加，古代故事才真正变成一面照今天的镜子——这才是"用现代视角重看原著"的精髓。

**背后的考量与取舍**

1. **为什么是"装眼镜"而不是"改故事"**：现代视角只用于"理解"，绝不用于"篡改"。我们一个字都不改原著情节——你扮演的是"如果我是林冲会怎么选"，而不是"我来给林冲改命"。改了原著，照见的就不再是经典的重量，而是同人创作的轻飘。这是不可退让的红线。
2. **为什么"结构层"最珍贵**：大多数解读止步于"点评人物"。但现代视角能给古人的最珍贵的东西，是命名那个"让他别无选择的系统"——这让锚点不是要你内疚（"你不够好"），而是让你看清（"是那个结构本就不给人留活路"）。
3. **为什么要"时空折叠"这一步**：光有抽象的现代标签还不够。我们在结算时强制把"角色原著里的一个真实高光场景"直接对折到"你今天的一个具体处境"上——"他当时的 X 就是你今天的 Y"。抽象的共鸣，要落到一个具体画面上，才真的击中人。
4. **取舍**：坚持忠于原著，意味着我们放弃了"魔改爽文"那种更抓眼球的可能性。我们认为值得——因为这个产品的根，是"读懂经典"，不是"消费经典"。

**怎么做到的（对应代码）**：

1. **困境库自带「现代解码器」**（`dilemma-library.ts`）。每个困境有三层：
   - `core`：古今通用的价值冲突内核（如「服从体制 vs 坚守原则」）；
   - `modernContext`：翻译成今天的处境（*「明知上面的决定是错的，执行了没事，不执行就是你的问题」*）；
   - `modernTag`：一个当代社会焦虑标签（*「职场 PUA 受害者」「35 岁危机」「沉默的共谋者」*）；
   - `modernTension`：一句带锐度的结构性命名（*「当服从被包装成职业素养，个人的道德判断就被系统性剥夺了」*）。
2. **角色定位就是一次现代翻译**（`character-dna.ts` → `modernMapping`，即角色的 tagline）：用现代职场/人际语言，一句话翻译这个古人的处境。
3. **「时空折叠」把两个时代焊在一起**（`ending-narration` 第三段）：结算时强制输出一个 JSON——`ancientScene`（原著真实场景）+ `modernScene`（映射到今天的处境）+ `bridge`（一句话打通两个时代：*「他当时的 X 就是你今天的 Y」*）。
4. **红线：现代视角只用于「理解」，绝不用于「篡改」**（`init/route.ts` → `canonicalBlock` 原著锚点保护）：
   - 场景、人物、道具、地点必须有原著依据，不得凭空发明；
   - 玩家的「选择」是对原著情境的**视角代入**（「如果你是他，你会怎么做」），而不是改写原著；
   - *「困境的现代语境翻译是为了帮玩家理解，不是替代原著场景——场景本身必须忠于原著」*。

> 一句话：我们不改一个字的原著，只是递给你一副能看懂它的现代眼镜——当你发现林冲的「忍」就是你的「忍」，那一刻，才叫真正读懂了书。

## 原则十：故事构建——「五层核心驱动」是所有困境的地基

**目标**：一个抉择要能测出价值观，前提是它戳中的是人真正在乎的东西。我们需要一把统一的尺子来判断「这个困境够不够深」。

**为什么这么设计**：不是所有两难都值得测。问"你今晚吃什么"测不出价值观，问"要不要为了活下去放弃尊严"才行。我们需要一把"深度标尺"来筛困境——越往深，越接近一个人不肯让渡的东西。五层由浅到深排列，正是为了让故事能"逐步下潜"：前期用浅层困境（生存、利益）快速拉人入戏，后期把人一路逼到深层（意义、信念）摊牌。它同时也是选角标尺——撑不起深层困境的角色，不配做主角。

**怎么做到的**（`api/reader/analyze/route.ts` 的系统提示词 · 已实现）：

我们给 AI 定义了一套**由浅到深的五层核心驱动**：

> **生存 → 利益 → 尊严/面子 → 情感关系 → 意义/信念**

- 越往深，越接近一个人不肯让渡的底线。浅层困境（生存/利益）张力直接、代入快；深层困境（意义/信念）才能真正照见价值观。
- 一个好的故事，要让玩家的抉择**沿着这五层逐步下潜**——前期在利益层博弈，后期被逼到意义层摊牌。
- 这套框架同时约束了「选角标准」：角色必须**多次面对真实两难、贯穿主线、有现代共情点**——不是随便谁都能撑起一局。

> 一句话：五层驱动是困境的「深度标尺」，保证我们问的每一个问题，问的都是「你到底是谁」，而不是「你今晚吃什么」。

## 原则十一：戏剧弧线——「起承转合」是硬约束，不是建议

**目标**：AI 生成的内容最容易犯的错是「平」——每一幕强度一样，玩家很快麻木。我们要强制一条从平静到爆发的情绪曲线。

**为什么这么设计**：AI 自由发挥时最容易犯的错就是"平"——每幕强度差不多，玩家很快麻木、弃局。而好的戏剧张力必须是一条爬升曲线。我们不信任 AI 会自觉控制节奏，所以把"什么时候该克制、什么时候能上强度"从"建议"升级成"代码硬约束"：前期强制克制（不许上极端选项），后期强制爬坡（逼出不可逆抉择）。把节奏交给规则、把演绎交给 AI，曲线才不会塌。

**怎么做到的**（`analyze/route.ts` 系统提示 + `next-act/route.ts` 强度调度 · 已实现）：

1. **四段式硬约束**写进系统提示，每一幕强度被明确规定：
   - **起（第1幕）**：平静日常，矛盾未激化，只出日常两难，**禁止极端情形**；
   - **承（第2幕）**：矛盾升温，压力从外部逼近，中等难度，**无陷阱**；
   - **转（第3幕起）**：局势骤变，被逼到墙角，**允许出现第一个陷阱选项**；
   - **合（最后一幕）**：最高压时刻，核心价值观被逼出极端抉择，**陷阱概率最高**。
2. **困境强度随阶段自动升级**（`next-act/route.ts`）：普通局困境强度不固定——`起→1`、`转→2`、`合/尾声→3`，由 `storyPhase` 实时决定。曲线是代码调度出来的，不靠 AI 自觉。
3. **陷阱（不可逆选项）铁律**：`isTrap=true` 只能出现在第 3 幕及以后（普通局 `actNumber>=3`），每局最多 2 个、同一幕至多 1 个，且必须符合剧情逻辑——是角色在绝境下真实可能做的选择，不是为虐而虐。

> 一句话：情绪曲线不能交给运气。我们把「什么时候能上强度、什么时候必须克制」写成代码规则，AI 只能在框里发挥。

## 原则十二：抉择设计——每个选项都是「三件套」，测的是动机不是行为

**目标**：如果玩家只看到「A / B / C」三个行为选项，他会用「哪个看起来更聪明」来选，而不是遵从内心。我们要让每个选项暴露它背后的**真实动机**和**代价**，逼玩家面对的是价值排序，而非策略博弈。

**为什么这么设计**：如果选项只是三行干巴巴的行为（「甲/乙/丙」），玩家会用"哪个看起来更聪明/更划算"来选——那是策略博弈，不是价值表达。要逼出真实的价值排序，就得把每个选项背后的**动机**和**代价**摊到明面上：先用内心独白让玩家"认领"这个动机（"对，我就是这么想的"），再用点破语把代价说穿，最后用社会标签把它锚回当代。让人面对的不再是"选哪个更划算"，而是"我到底是谁"。

**怎么做到的**（`init/route.ts` 的选项 JSON 结构 · 已实现）：

每个选项强制携带一套「三件套」：

1. **`innerVoice`（内心独白）**：角色在那一刻**赤裸真实的动机**，50 字，不是道德表态——替玩家说出「我其实是这么想的」。
2. **`revealText`（点破语）**：30 字白话，直击「这个选择到底意味着什么」，不评判对错，只把代价摊开。
3. **`socialTag`（社会焦虑标签）**：把古代抉择翻译成当代人一眼认出的处境标签（如「沉默的共谋者」「35岁危机」），也是后续统计核心执念、反查结构性张力的锚点。

配套还有：**即时后果**（`consequenceMap`，选完立刻看到涟漪）、**自保/牺牲语义标记**（`isSelfPreserve`/`isSacrifice`，喂给行为计数器）。

**关键约束·选项与困境绑定（`init/route.ts` 生成约束 · 已实现）**：三个选项不是三件互不相干的事，而是**同一个核心困境的三种价值排序解法**——甲=保全自己、乙=中间/折中、丙=承担最重的代价。三者被强制设计成**势均力敌、都难受、没有明显正确答案**。这是为了堵住一个漏洞：若三个选项难度不等，玩家会直接挑"看起来最优/最安全"的那个，测出的是"谁更会算"，不是"你更看重什么"。只有当三条路都同样疼，你的选择才暴露真实的价值排序。

> 一句话：我们不让你选「做什么」，我们让你选「为什么」——把动机、代价、和它的当代名字全摊在选项里；而且三条路一样疼，你没法靠"选更划算的"来逃避表态。

## 原则十三：为何要「两次分析」——一次测不出价值观，只能测出人设

这是最容易被忽略、却最关键的设计动机，单独说清楚。

**问题**：只玩一局，结论有一个致命歧义——**你选的到底是「真实的你」，还是「你想扮演的那个体面的你」？** 常态下大多数人都能表现得忠诚、善良、有底线，因为**代价还没高到需要暴露真实排序**。单次分析，测出的往往是「人设」而非「人」。

**我们的解法：两次分析 + 差异即真相。**

1. **第一次（普通局）测「倾向」**：在可承受的代价下，看你**自然状态下**倾向怎么选——你的「舒适区人格」。
2. **第二次（极压局）测「底线」**：把代价拉到不可逆，看你**在无法体面时**最后守住/最先放弃什么——你的「压力下人格」。
3. **真正的洞察在两者之差**（`compare-narration/route.ts`）：
   - **没变** → 这才是真正的**底线**（代码会明确告诉你「这是真正的底线」）。常态和极限都选一样，说明这个价值不是表演，是刻进去的。
   - **变了（翻转）** → 暴露了你的**体面成本**：常态的善良/忠诚，在压力下被交易掉了。不是指责，而是让你看见「你以为的自己」和「压力下的自己」之间那道缝。
4. **所以极压不是「困难模式」，而是「显影液」**——它唯一的目的，是把第一张照片里看不清的那部分冲洗出来。

> 一句话：一次分析给你一张自画像，两次分析给你一面照妖镜——而人最需要认识的，恰恰是照妖镜里那个自己。

## 原则十四：责任分工——「角色 DNA」保真，「困境库」供料，两者解耦

**目标**：既要每局忠于特定角色（林冲就是林冲），又要困境足够多样、现代，还要能低成本扩展。把这两件事揉在一起会互相拖累。

**为什么这么设计**：如果把"这个角色是谁"和"他会遇到什么困境"写在一起，两者就会互相拖累——想扩充困境得改遍所有角色，想加个角色得重配一堆困境。所以我们把它拆成两个正交的模块：角色 DNA 只管"保真"（他的伤口、底线、原著锚点），困境库只管"供料"（结构化、现代化、可复用的两难），运行时才临时拼装。这样两边能各自独立进化：困境库扩一百条，不动任何角色；新增一个角色，直接复用现成困境。

**怎么做到的**（`character-dna.ts` × `dilemma-library.ts` · 已实现）：

1. **角色 DNA 负责「他是谁」**：核心伤口、在保护什么、最怕失去什么、专属价值四轴、原著情节锚点（`canonicalMoments`）、现代映射——保证叙事**忠于这个人**。
2. **困境库负责「让他面对什么」**：按场域分类的结构化困境，自带现代解码器和 `storyAppeal` 吸引力权重——保证抉择**有张力、够现代、可复用**。
3. **两者在生成时才组装**：`selectDilemmas` 先按角色场域筛出候选困境，再叠加**贴合度加权**——把角色的核心伤口 / 在保护什么 / 最怕失去，和每条候选困境（核心矛盾、张力、语境）做 bigram 关键词重叠打分（`affinityScore`），**优先抽出最戳这个角色的困境**，减少"硬凑"。`callActGenerator` 再把「角色真实处境」和「困境现代张力」焊进一幕。角色变了不必改困境库，困境库扩充也不影响角色保真。
4. **新角色同样吃到贴合匹配**：预置角色用 DNA 的三字段做匹配；用户自己输入的书/角色（AI 现生成 DNA）走 `driveAnalysis`（同为[核心伤口, 在保护什么, 最怕失去]），运行时统一拼成贴合度文本——所以新角色也能抽到最戳自己的困境，而非退回纯随机。

> 一句话：角色 DNA 是「主语」，困境库是「谓语」，运行时才拼成句子——各自独立进化，互不拖累。

## 原则十五：对比页——「同一把标尺」才能看清落差

**目标**：两次分析并排时，如果两局用不同的视觉尺度呈现，落差就会被视觉噪声淹没。要让「顺境的你 vs 绝境的你」的距离一眼可见，必须把两局拉到同一套标尺上。

**为什么这么设计**：两局对照是产品的高潮，但"对照"极易被呈现方式毁掉——如果常态局和极压局各用各的刻度画图，玩家看到的是两张风格不同的图，而不是"同一个人的两种状态"。要让落差成为洞察，前提是消除一切与落差无关的视觉差异：同轴、同刻度、同排版，只让"数据"不同。落差这才浮出来，且不掺假。

**怎么做到的**（`compare-narration/route.ts` + 极压对比页 · 已实现）：

1. **占比拉齐**：对比页把常态局和极压局的选择轨迹、价值占比、结构性张力**并排放在同一套视觉标尺里**——同样的轴、同样的刻度、同样的呈现方式，只有数据不同。
2. **逐轴 diff 量化**：每条价值轴都算出「普通分 → 极压分」的偏移量并标出方向，元轴同理，让「变了多少、往哪变」变成可读的数字而非模糊感觉。
3. **分岔点定位**：旁白强制指出两个版本「最大的分岔点是哪一幕」，把抽象的落差落到一个具体时刻上。

> 一句话：对比不是把两张成绩单摆在一起，而是把它们套进同一个坐标系——落差才不会骗人。

## 原则十六：代价逻辑自洽——反转是「关系反噬」，不是「天降惩罚」

**目标**：极端选择必须有代价，否则测不出底线；但代价一旦变成系统凭空的「惩罚」，玩家就会觉得被审判、被作弊，整套「无倾向」的信任就崩了。代价必须是**你过往行为合乎逻辑的自然反噬**。

**为什么这么设计**：这一条守的是"信任"。前面所有原则（尤其原则一的中立）都在建立"这面镜子不评判你"的信任，而代价机制是最容易把它砸碎的地方——只要代价显得像"因为你选错了，所以罚你"，玩家立刻就会退回到"揣摩正确答案"的防御姿态，前功尽弃。所以代价不能是天降的惩罚，必须是"你反复某种倾向后，那个倾向合乎逻辑地反噬了你自己"。它发生在剧情里、合乎人设，让人认的是"这是我招来的"，而不是"系统在罚我"。镜子可以让你难受，但不能让你觉得它在打分。

**怎么做到的**（`narrative-principles.ts` → `TWIST_RULES` · 已实现）：

1. **反噬发生在故事里，不是弹窗**：连续自保 → 你一直在保护的东西正被悄悄拿走；连续牺牲 → 你的牺牲被当成理所当然、甚至被利用。这些都不是「Game Over 弹窗」，而是**合乎人设的剧情自然反应**——像现实里价值倾斜在某个转角合理地撞回你自己。
2. **每种反转只触发一次**（`onceOnly`），避免变成惩罚性套路。
3. **结局同理是「延伸」不是「审判」**（`ENDING_PRINCIPLES`）：只描述选择累积把你带到了哪里，至少提及一个你做过的具体选择，不惩罚也不表扬——只把因果链摊开。

**配套：锚点的硬约束**（`ending-narration/route.ts`）——为保证锚点「扎心而不空洞」，代码强制：画面 ≤20 字、自省问题 ≤25 字、**必须从本局真实情节生长、禁止通用比喻**；且分析维度除选择模式/价值取向外，还纳入「底层心理（元轴偏移）」和「情绪底色」。

> 一句话：我们让代价长在故事里，而不是从天上砸下来——因为一面会「惩罚」你的镜子，你不会再信它照出的样子。

## 原则十七：选择→反馈闭环——连贯、精彩、意外，三位一体

**目标**：交互叙事最核心、也最容易崩的一环，是"你点下一个选择之后发生了什么"。这一下如果处理不好，故事会犯三种病：**断片**（前后接不上）、**平庸**（每幕一个味道）、**可预测**（你早就猜到下一步）。我们要让每一次选择之后，故事同时做到连贯、精彩、意外——这三件事不是三个功能，而是同一条"消化你的选择、再生成下一幕"的闭环上的三个面。

**关照哪些维度，为什么是这几个**

一次选择落下后，系统要在同一个瞬间兼顾三个维度，缺一个都会露馅：

- **连贯维度——"接得上"**：下一幕必须记得你刚才做了什么、故事里还有哪些没解决的悬念、场景里有哪些具体的人和物。否则再精彩的单幕也会像散落的碎片。
- **精彩维度——"有张力"**：下一幕不能是平淡的过场。既要让你立刻看到这次选择激起的"涟漪"（即时后果），又要保证接下来的困境本身足够有戏。
- **意外维度——"猜不到"**：如果每一步都在意料之中，选择就失去了重量。故事要能在你反复某种倾向时，冷不丁地反噬你；也要在题材抽取上保留随机，让重玩不撞车。

**背后的考量与取舍**

1. **为什么把三者当成"一条链"而不是三个独立功能**：它们其实共用同一个入口——"你的这次选择"。连贯是"回头看"（消化你已经做的），精彩是"当下给"（立刻反馈+上强度），意外是"往前埋"（根据你的模式暗中转向）。把它们串成一条闭环，才能保证三者不打架：意外必须建立在连贯之上（反转也得接得住前文），精彩必须服务于当下的张力曲线（见原则十一）。
2. **为什么"意外"要来自你的行为、而不是随机惊吓**：廉价的意外是编剧硬拗的巧合。我们的意外是"你连续自保 → 你保护的东西正在流失"这种**因你而起的反噬**——它既出乎意料，又在事后想来"合乎逻辑"。这是"精彩的意外"和"莫名其妙的意外"的分界（呼应原则十六）。
3. **为什么"连贯"要靠强制引用、而不是指望 AI 记性**：长对话里 AI 会忘掉三幕前的细节。所以我们不指望它自觉，而是把上一幕产出的具体场景锚点（地名/人名/道具）抽出来，**强制要求下一幕至少引用一个**——把"连贯"变成硬约束，而非祈祷。
4. **取舍**：随机性（意外）和戏剧最优（精彩）是有张力的——每次都挑最精彩的困境会牺牲新鲜感。我们用"加权随机"折中：好戏更常出现，但不保证每局相同（见原则八）。

**怎么做到的（对应代码）**：

1. **连贯——三重记忆回喂**（`world-state.ts`）：每次 `applyChoice` 都会把这次选择追加进 `choiceHistory`、把新悬念并入 `pendingTensions`（最多留 6 条）、把新场景细节并入 `narrativeAnchors`（去重留 4 条）；下一幕生成前，`summarizeState` 把"近期选择 + 未解伏笔 + 场景锚点 + 情绪基调"打包回喂给 AI，并**强制本幕至少引用一个已有场景锚点**。
2. **精彩——即时涟漪 + 张力抽取**：每个选项自带 `consequenceMap`（选完立刻显示这一步的即时后果），让选择"看得见回声"；下一幕的困境用 `selectDilemmas` + `weightedSample`（`storyAppeal²` 加权）抽取，让高张力困境更常登场。
3. **意外——因你而起的反噬**（`narrative-principles.ts` → `TWIST_RULES` / `ESCALATION_RULES`）：系统实时监测你的连续倾向与价值轴极值，命中即注入一次性反转（如"你保护的正在流失"）；第 5 幕起还强制每个选择与你之前的选择形成因果连接，让意外始终扎根在你自己的轨迹上。

> 一句话：你落下的每一个选择，都会被故事记住、被立刻回应、再在你意想不到处回撞——连贯让它可信，精彩让它好看，意外让它有重量。

## 🚧 构想区：讨论过、但尚未写进代码的设计

> 以下原则来自我们的设计讨论，**目前尚未在代码中实现**，但我们认为它们很有价值，特此记录。标注为「构想」以示区别——请勿当作已上线功能。

- **【构想·未落地】跨局价值观档案**：元价值轴（原则六）已具备跨局可比的技术基础，但还没有一个「个人价值观档案」页把你玩过的多个角色的 8 维画像沉淀、叠加、对比。构想：玩得越多，越能看出你稳定的价值底色 vs 因角色而异的浮动层。
- **【构想·未落地】「第三次分析」——时间维度**：普通/极压是「压力维度」的两次。讨论中还提过引入「时间维度」——隔一段时间重玩同一角色，对比「过去的你」和「现在的你」，看价值观是否随人生阶段漂移。
- **【构想·未落地】选择的「机会成本」显影**：每次选一个选项，另外两条路会怎样？构想是在结算时让 AI 补一段「你没选的那条路」的平行走向——因为价值观不仅体现在你选了什么，也体现在你甘愿放弃什么。
- **【构想·未落地】同一困境的「群体分布」**：把「你的选择」放进「所有玩过这个角色的人的选择分布」，不为从众攀比，而是让人看见「原来我在这个两难上是少数派/多数派」，更清楚自己的位置。（需后端聚合，当前未做。）
- **【构想·未落地】反「表演」检测**：讨论中担心玩家「为了拿到某个结论而刻意选」。构想是通过选择耗时、是否反复横跳、是否在低代价时也做高代价选择等信号，识别「表演性选择」并在旁白里温和点破。
- **【部分实现·可深化】结构性张力「命名库」**：困境库的 `modernTension` 已在做「给古人处境一个当代名字」，讨论中希望扩成更系统的「结构性困境词典」（如「幸存者内疚」「习得性无助」「道德许可效应」），提升锚点的认知锐度。目前逐条手写，尚未体系化。
- **【构想·未落地】关系反噬可视化**：目前反转反噬（原则十六）体现在剧情文字里。构想是把「谁因为你的选择改变了对你的态度」做成一张**动态关系网络图**，让你的价值倾斜对周围人的影响一眼可见。
- **【构想·未落地】价值人格命名 + 分享卡**：为每种价值组合起一个有传播力的**人格名**（如「夹缝生存者」「燃烧的理想主义者」），做成可分享卡片。目前分享的是选择轨迹与结果链接，尚无人格命名。
- **【构想·未落地】多角色视角交叉复盘**：同一个故事提供多个角色的视角支线，最终汇聚成一张「全景复盘」，让你看到自己的选择如何影响了其他角色的处境。目前是单角色深挖。

## 附：一次完整体验里，这些原则如何串起来

```
选角色 → 生成专属价值轴(初始全50，绝对中立·原则一)
   │
   ├─每一幕：状态机定节奏(原则七) + 规则引擎按你的模式注入反转/升级(原则八)
   │        困境自带现代解码器(原则九) + 三选项等价无对错(原则一)
   │
   ├─每次选择：隐藏打分累积进价值轴 + 行为计数(原则二)
   │
   ▼
普通局结算 → 分层锚点(原则四) + 时空折叠(原则九) + 映射到6元轴(原则六)
   │
   ▼
极压局 → 读普通局数据·专打软肋(原则三)，全程无软着陆
   │
   ▼
极压对比 → 逐幕翻转检测 + 三层差异量化 + 找到分岔点(原则五)
           照见「常态的你」与「极限的你」，认出你真正的底线
```
